HACKATHON LEROBOT ROBOTEKIN
Web app that works as interface between customer and a So101 Robot arm model

Start by running policy_server.py through an activated condo environment.

PLACEHOLDERS!!

Policy paths are harcoded inside policy_server.py, to set up, make sure you know each inference policy path and hardcoded into its respective variable

Similarly, some things like so101 robot port, camera index, robot id in s1.py are meant to be edited according to your data and configuration.
